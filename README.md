# Physics Coolnut Lesson — Free Falling

เว็บแอปทบทวนและสอบเก็บคะแนนเรื่อง **การตกอย่างเสรี (Free Falling)** สำหรับใช้เป็นบทเรียนขนาดเล็กในชุด **Physics Coolnut Lesson**

โปรเจกต์นี้ออกแบบให้เรียบง่าย ใช้งานได้ทันทีด้วยไฟล์ HTML เพียง 2 หน้า โดยยึดเนื้อหาตามชีทที่ใช้สอนจริง และไม่ขยายข้อสอบเกินขอบเขตเนื้อหาดังกล่าว

---

## 1. เป้าหมายของบทเรียน

บทนี้ไม่ได้มีเป้าหมายให้ผู้เรียนจำสูตร SUVAT เพิ่มเติม แต่เน้นให้เข้าใจว่า การตกอย่างเสรีใกล้ผิวโลกสามารถประมาณเป็นการเคลื่อนที่ด้วยความเร่งคงที่ได้ โดยกำหนดแกน

\[
+y \text{ ชี้ขึ้น}
\]

ดังนั้น

\[
g=-9.8\ \text{m/s}^2
\]

ผู้เรียนจึงต้องให้ความสำคัญกับ 3 เรื่องพร้อมกัน:

1. การเลือกสมการให้เหมาะกับสถานการณ์
2. เครื่องหมายบวก/ลบของปริมาณเวกเตอร์
3. หน่วยของคำตอบ

---

## 2. สมการที่ใช้ในบทนี้

ใช้สมการ Free Falling 4 สมการเท่านั้น

\[
S_y=u_yt+\frac{1}{2}gt^2
\]

\[
S_y=v_yt-\frac{1}{2}gt^2
\]

\[
v_y=u_y+gt
\]

\[
v_y^2=u_y^2+2gS_y
\]

> สมการ \(s=\frac{u+v}{2}t\) ไม่ถูกนำมาใช้ในบทนี้ เพราะต้องการให้ผู้เรียนเห็นบทบาทของ \(g\) โดยตรงตลอดการแก้ปัญหา

## 4. รูปแบบข้อสอบ

### ข้อ 1 — Random Free Falling Equation

**2.00 คะแนน**

ระบบสุ่มโจทย์จาก 1 ใน 4 Equation Families และสุ่มเลขฐาน 1–99 เพื่อนำมาบวกเลขที่นักเรียนในการสร้างค่าตัวเลขหลักของโจทย์

| Family | สมการ |
|---|---|
| 1 | \(S_y=u_yt+\frac12gt^2\) |
| 2 | \(S_y=v_yt-\frac12gt^2\) |
| 3 | \(v_y=u_y+gt\) |
| 4 | \(v_y^2=u_y^2+2gS_y\) |

Family 4 ออกแบบให้ผู้เรียนต้องพิจารณาทิศทางหลังถอดราก เช่น เมื่อวัตถุกำลังตกกลับลงมา คำตอบของ \(v_y\) ต้องเป็นลบ

#### การให้คะแนนข้อ 1

| องค์ประกอบ | คะแนน |
|---|---:|
| ค่าตัวเลข/ขนาด | 1.00 |
| เครื่องหมาย \(+\) / \(-\) | 0.50 |
| หน่วย | 0.50 |
| **รวม** | **2.00** |

ระบบตรวจเครื่องหมายแยกจากขนาดของตัวเลข เพื่อให้สามารถให้ Partial Credit ได้

ตัวอย่าง หากคำตอบที่ถูกต้องคือ

\[
v_y=-39.40\ \text{m/s}
\]

ผู้เรียนที่ตอบขนาดถูก แต่เลือกเครื่องหมายผิด ยังสามารถได้คะแนนในส่วนค่าตัวเลขและหน่วย

|---|---:|
| ค่าตัวเลข | 1.00 |

| **รวม** | **1.50** |

## 6. กติกาเรื่องเครื่องหมาย

ตลอดทั้งบทกำหนด

\[
+y \uparrow
\]

ดังนั้น

\[
g=-9.8\ \text{m/s}^2
\]

แนวคิดที่ใช้:

- โยนขึ้น → \(u_y>0\)
- เคลื่อนขึ้น → \(v_y>0\)
- เคลื่อนลง → \(v_y<0\)
- การกระจัดเหนือจุดอ้างอิง → \(S_y>0\)
- การกระจัดใต้จุดอ้างอิง → \(S_y<0\)
- จุดสูงสุด → \(v_y=0\)
- เวลาและความสูงเป็นค่าบวก

ข้อ 1 จึงแยกช่องตอบออกเป็น

1. เครื่องหมาย
2. ค่าตัวเลข/ขนาด
3. หน่วย

เพื่อประเมินความเข้าใจเรื่องทิศทางโดยตรง

## 7. Randomization

### Practice

ใน `index.html`

- ผู้เรียนกำหนดเลขที่ 1–99
- ระบบสุ่ม 1 ใน 4 Equation Families
- ระบบสุ่มเลขฐาน 1–99 แล้วบวกกับเลขที่นักเรียนเพื่อสร้างค่าหลักของข้อ 1
- สามารถสุ่มโจทย์ใหม่ได้ไม่จำกัด

### Exam

ใน `score-exam.html`

- เมื่อเริ่มสอบ ระบบสุ่ม Equation Family ของข้อ 1 เพียงครั้งเดียว
- ข้อ 1 สุ่มเลขฐาน 1–99 แล้วบวกกับเลขที่นักเรียน
- ข้อ 2 สุ่มเลขฐาน 1–99 แล้วใช้ \(u_y=\text{เลขฐานสุ่ม}+\text{เลขที่}\)
- เลขฐานของทั้งสองข้อจะคงเดิมตลอดการสอบครั้งนั้น รวมถึงเมื่อ reload
- Session จะรักษาโจทย์เดิมและคำตอบที่กรอกไว้ระหว่างการ reload ในแท็บเดิม

## 9. การตรวจคำตอบ

ค่าตัวเลขใช้ tolerance

\[
\pm 0.05
\]

ดังนั้นค่าที่แตกต่างเล็กน้อยจากการปัดเศษยังสามารถตรวจเป็นถูกได้

ตัวอย่าง:

```text
คำตอบจริง = 40.40
40.39 → ผ่าน
40.40 → ผ่าน
40.44 → ผ่าน
40.50 → ไม่ผ่าน
```

> UI แนะนำให้ตอบเป็นทศนิยม 2 ตำแหน่ง แต่ระบบตรวจจากค่าตัวเลขภายใน tolerance ไม่ได้ตรวจรูปแบบ string ว่าต้องมี 2 ตำแหน่งเสมอ

## 14. ข้อจำกัด

ระบบนี้ออกแบบสำหรับ **การทบทวนและสอบในชั้นเรียนภายใต้การควบคุมของครู**

เนื่องจากเป็น Pure Frontend:

- Logic การสร้างโจทย์อยู่ใน JavaScript ฝั่ง Client
- ผู้ใช้ที่มีความรู้ด้าน Developer Tools สามารถตรวจ Source Code ได้
- คะแนนเก็บใน Browser ของเครื่องนั้น
- ไม่มีระบบ Login
- ไม่มีฐานข้อมูลส่วนกลาง
- ไม่มีระบบป้องกันการสอบซ้ำระดับ High-stakes

จึงไม่ควรใช้แทนระบบสอบที่ต้องการ Security สูงโดยไม่มี Backend เพิ่มเติม

## 15. Design Philosophy

เว็บนี้ยึดรูปแบบของ **Physics Coolnut Lesson**

```text
Learn
→ Worked Example
→ Random Practice
→ Hint
→ Solution
→ Score Exam
```

แต่ปรับ Scale ให้เหมาะกับธรรมชาติของบท Free Falling ซึ่งเป็นบทเล็กและมีคะแนนเพียง 5 คะแนน

หลักสำคัญคือ

> **ไม่ทำเว็บให้ซับซ้อนเกิน Learning Outcome ที่ต้องการวัด**

ดังนั้นบทนี้จึงมีเพียง 2 แกนหลัก:

```text
1. ใช้สมการ Free Falling 4 สมการให้ถูก
2. เข้าใจจุดสูงสุด vᵧ = 0 และหาเวลา/ความสูงสูงสุดได้
```

พร้อมประเมิน **ค่าตัวเลข + เครื่องหมาย + หน่วย** ให้ตรงกับสิ่งที่ใช้สอนจริง
